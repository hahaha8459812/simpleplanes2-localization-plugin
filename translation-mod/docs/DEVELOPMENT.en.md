# Development And Build

[中文](DEVELOPMENT.md)

For developers and maintainers. For player installation and usage see the [root README](../../README.en.md).

## Project Layout

```text
translation-mod/
  src/                                  # BepInEx/Harmony plugin source
  content/settings.release.json          # release settings, usually translate mode
  content/settings.dev.json              # dev collection settings, usually collect mode
  content/translations/zh-CN.fragments/  # translation source fragments
  content/translations/zh-CN.json        # generated merged catalog, do not edit manually
  docs/                                  # development, translation, and release docs
  build.ps1                              # build DLL, merge catalog, package release/dev zips
```

Only edit translation source fragments:

```text
translation-mod/content/translations/zh-CN.fragments/*.json
```

Do not manually edit:

```text
translation-mod/content/translations/zh-CN.json
```

`zh-CN.json` is regenerated by `build.ps1`.

## Build

```powershell
cd translation-mod
.\\build.ps1
```

Build outputs:

```text
translation-mod/artifacts/SimplePlanes2Translation.dll
translation-mod/release/SimplePlanes2TranslationMod-Release.zip
translation-mod/release/SimplePlanes2TranslationMod-Dev.zip
```

The release zip contains a single `BepInEx/plugins/SimplePlanes2Translation/` tree; extract it into the game root:

```text
BepInEx/plugins/SimplePlanes2Translation/SimplePlanes2Translation.dll
BepInEx/plugins/SimplePlanes2Translation/settings.json
BepInEx/plugins/SimplePlanes2Translation/translations/zh-CN.json
BepInEx/plugins/SimplePlanes2Translation/fonts/
```

Release packages do not bundle BepInEx; the player installs BepInEx 5 Mono x64 separately.

For translation-only changes, build and copy the new `zh-CN.json` into the game plugin directory, then press `F2` in game.

For C# changes, rebuild the DLL, close the game, replace the DLL, and restart the game.

## Runtime Modes

Runtime settings live in:

```text
SimplePlanes 2\BepInEx\plugins\SimplePlanes2Translation\settings.json
```

Common modes:

- `translate`: translate only, without logging missing text. Used by regular players.
- `collect`: collect text only, without translating.
- `hybrid`: translate and collect at the same time. Best for iterative translation work.

## Release

The repository includes a GitHub Actions release workflow, but compilation depends on game assemblies from:

```text
SimplePlanes 2_Data\Managed
```

Therefore automated release builds require a Windows self-hosted runner with the game installed, or an equivalent legally prepared Windows environment.

Tag release example:

```powershell
git tag v0.1.0
git push origin v0.1.0
```

You can also run `Build release packages` manually from GitHub Actions.
